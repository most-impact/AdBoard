# DiplomJava - Бэкенд приложения для объявлений

## Описание проекта
Бэкенд-часть веб-приложения для размещения объявлений с системой авторизации, ролевой моделью пользователей, CRUD-операциями для объявлений и комментариев, а также функционалом загрузки изображений.

## Функциональность
- **Аутентификация и авторизация** пользователей
- **Ролевая модель**: USER и ADMIN
- **CRUD-операции** для объявлений:
    - Создание, чтение, обновление, удаление объявлений
    - Пользователи могут управлять только своими объявлениями
    - Администраторы могут управлять всеми объявлениями
- **CRUD-операции** для комментариев:
    - Возможность оставлять комментарии к объявлениям
    - Пользователи могут управлять только своими комментариями
    - Администраторы могут управлять всеми комментариями
- **Работа с изображениями**:
    - Загрузка и отображение изображений объявлений
    - Аватары пользователей
- **Управление пользователями**:
    - Регистрация
    - Обновление профиля
    - Смена пароля

## Технологии
- **Java 17+**
- **Spring Boot 3.x**
- **Spring Security** - безопасность и авторизация
- **Spring Data JPA** - работа с базой данных
- **PostgreSQL** - система управления базами данных
- **Liquibase** - управление миграциями базы данных
- **MapStruct** - маппинг между сущностями и DTO
- **SpringDoc OpenAPI** - документация API (Swagger)
- **JUnit 5, Mockito** - тестирование
- **Maven** - управление зависимостями

## Структура проекта
### config/
Конфигурационные классы Spring Boot приложения.

### controller/
REST контроллеры для обработки HTTP запросов:
- `AdController` - операции с объявлениями
- `AuthController` - аутентификация и регистрация
- `ImageController` - работа с изображениями
- `UserController` - операции с пользователями

### dto/
Data Transfer Objects для передачи данных между слоями приложения.

### mapper/
MapStruct мапперы для преобразования между Entity и DTO.

### model/
JPA сущности, соответствующие таблицам базы данных.

### repository/
Spring Data JPA репозитории для доступа к данным.

### security/
Конфигурация Spring Security для аутентификации и авторизации.

### service/
Сервисный слой с бизнес-логикой приложения.

## API Endpoints

### Аутентификация
- `POST /login` - вход в систему
- `POST /register` - регистрация нового пользователя

### Пользователи
- `GET /users/me` - получить информацию о текущем пользователе
- `PATCH /users/me` - обновить информацию о текущем пользователе
- `POST /users/set_password` - сменить пароль
- `GET /users/{id}/avatar` - получить аватар пользователя
- `PATCH /users/me/image` - обновить аватар пользователя

### Объявления
- `GET /ads` - получить все объявления (с фильтрацией)
- `POST /ads` - создать новое объявление
- `GET /ads/{id}` - получить объявление по ID
- `DELETE /ads/{id}` - удалить объявление
- `PATCH /ads/{id}` - обновить объявление
- `GET /ads/me` - получить мои объявления
- `GET /ads/{adId}/comments` - получить комментарии к объявлению

### Комментарии
- `POST /ads/{adId}/comments` - добавить комментарий к объявлению
- `DELETE /ads/{adId}/comments/{commentId}` - удалить комментарий
- `PATCH /ads/{adId}/comments/{commentId}` - обновить комментарий

### Изображения
- `GET /images/{filename}` - получить изображение

## Установка и запуск

### Предварительные требования
1. Java 17 или выше
2. Maven 3.6+
3. PostgreSQL 12+

### Шаги установки
1. Клонировать репозиторий:
```bash
git clone <repository-url>
cd DiplomJava
```

2. Настройка базы данных:
```bash
# Создание базы данных PostgreSQL
createdb diplom_db
```

3. Конфигурация
Отредактируйте src/main/resources/application.properties:
```bash
spring.datasource.url=jdbc:postgresql://localhost:5432/diplom_db
spring.datasource.username=your_username
spring.datasource.password=your_password
```

4. Сборка и запуск
```bash
mvn clean install
mvn spring-boot:run
```
